Type these in the Keel shell (run `keel`), in the browser terminal (`keel serve`), or after `keel` in any terminal: `today` and `keel today` are the same.

Add `--json` to any command for machine-readable output. See [JSON output](/reference/json).

## Capture

### owe

New "I owe" commitment.

```text Usage
owe <what> @who due:<when> [+client/project] [from:meeting|slack:<link>] [#tag]
```

Lands in the project you are working on unless you add `+client/project`.

```bash Examples
owe send pricing deck @ravi due:thu
owe revised SOW @ravi due:mon +northwind/portal from:slack:https://acme.slack.com/archives/C1/p2
owe contract review @priya due:+3d #legal
```

### wait

New "waiting on" commitment.

```text Usage
wait <what> @who due:<when> [+client/project] [from:meeting|slack:<link>] [#tag]
```

```bash Examples
wait design files @meera due:fri
wait API keys @tom due:tomorrow +northwind/portal
```

### in

Capture to the inbox, sort it later.

```text Usage
in <anything> [+client/project]
```

No person or date needed. Sort it later with `triage`.

```bash Examples
in ask Ravi about the phase 2 budget
in check the contract renewal date +acme/website
```

### meeting

Capture promises as they happen: > owe, < waiting, anything else is a note. Asks questions as it goes.

```text Usage
meeting [+client/project] ["title"]
```

Then type one line per item: `> pricing deck to @ravi due:thu` for something you owe, `< design files from @meera due:fri` for something you wait on, anything else is a note. An empty line ends the meeting and asks before saving.

```bash Examples
meeting +acme/website "weekly sync"
```

## Daily

### today

Focus, due and late, waiting-on follow-ups, quiet projects.

```text Usage
today [+client]
```

Shows the project you are working on, your focus, what is due or late, follow-ups, the next three days and projects going quiet.

```bash Examples
today
today +acme
```

### focus

Pick today's top 3.

```text Usage
focus <c42> [c51] [c60] | focus clear
```

Up to three. Everything else stays visible below the line.

```bash Examples
focus c12 c15
focus clear
```

### ls

List commitments or the inbox, with filters.

```text Usage
ls [owe|wait|overdue|done|inbox] [+client] [@who]
```

```bash Examples
ls
ls owe
ls wait @meera
ls overdue +acme
ls inbox
```

### show

Details and history of one item.

```text Usage
show <c42|p7|i3>
```

```bash Examples
show c12
show p3
show i5
```

## Close the loop

### done

Mark a commitment done.

```text Usage
done <c42>
```

```bash Examples
done c12
```

### drop

Drop a commitment or inbox item.

```text Usage
drop <c42|i3>
```

```bash Examples
drop c12
drop i5
```

### renegotiate

Agree a new due date (counts differently from a silent slip).

```text Usage
renegotiate <c42> due:<when>
```

For a date you agreed with the other person. It counts differently from a silent slip in the weekly summary.

```bash Examples
renegotiate c12 due:mon
```

### nudge

Record that you followed up on a waiting-on item.

```text Usage
nudge <c42>
```

Records that you followed up on something you are waiting on.

```bash Examples
nudge c15
```

### set

Edit fields of a commitment or project.

```text Usage
set <c42|p7> [title:"..."] [due:<when>] [@who] [+client/project] [status:<status>] [slug:<new-slug>]
```

```bash Examples
set c12 title:"send revised deck" due:fri
set c12 @priya +northwind/portal
set p3 status:paused
set p3 title:"Website v2" slug:site
```

## Projects and context

### switch

Change context; asks for a resume note on the way out. Asks questions as it goes.

```text Usage
switch <client/project> [where:"..." next:"..." unsure:"..."]
```

Asks three short questions about the project you are leaving (where you are, what is next, what you are unsure about), then shows the note you left on the one you are going to.

```bash Examples
switch northwind/portal
switch acme/website where:"pricing page half done" next:"send deck"
```

### park

Save a resume note and leave the project. Asks questions as it goes.

```text Usage
park [where:"..." next:"..." unsure:"..."] [+client/project]
```

Saves a resume note and leaves you in no project.

```bash Examples
park
park where:"draft sent" next:"wait for feedback"
```

### client

Add, rename, archive or delete clients. Asks questions as it goes.

```text Usage
client new|rename|archive|unarchive|delete <slug> ... | clients [--all]
```

Deleting shows what goes with the client and asks you to type its slug. `--yes` skips the question in scripts.

```bash Examples
client new acme "Acme Corp"
clients
client rename acme "Acme Inc"
client rename acme slug:acme-inc
client archive acme
client delete acme
```

### project

Add, list or delete projects (rename with set p7 title:"..." slug:...). Asks questions as it goes.

```text Usage
project new <client/slug> "<Name>" | project delete <p7> | projects [--all]
```

```bash Examples
project new acme/website "Website rebuild"
projects
project delete p3
```

### person

List people, set their names, merge duplicates.

```text Usage
person rename @ravi "Ravi Kumar" | person merge @rav @ravi | people
```

```bash Examples
people
person rename @ravi "Ravi Kumar"
person merge @rav @ravi
```

## Weekly

### triage

Walk the inbox: turn each item into owe, wait, keep or drop. Asks questions as it goes.

```text Usage
triage
```

Walks the inbox one item at a time: turn it into an owe or wait, keep it, or drop it.

```bash Examples
triage
```

### review

Guided weekly review, about 30 minutes. Asks questions as it goes.

```text Usage
review
```

The Friday review: inbox, overdue items, follow-ups, resume notes, next week’s priorities, then the week summary.

```bash Examples
review
```

### summary

Kept, renegotiated, slipped, waiting, time per client.

```text Usage
summary [day|week|last] [+client]
```

```bash Examples
summary
summary day
summary last +acme
```

## Data and settings

### export

Export everything as JSON (or Markdown to read). Your data is always yours.

```text Usage
export [--json|--md]
```

```bash Examples
export > keel-backup.json
export --md > keel.md
```

### import

Restore a JSON export into an empty database.

```text Usage
import <file.json>
```

Only into an empty database, so nothing is ever overwritten.

```bash Examples
import keel-backup.json
```

### theme

Pick the color theme.

```text Usage
theme [light|dark|auto]
```

```bash Examples
theme
theme light
theme auto
```

### help

Show all commands.

```text Usage
help
```

```bash Examples
help
help --json
```

## The keel program

These run in your terminal, outside the Keel shell.

### keel

Open the Keel shell: type commands without the keel prefix, with Tab completion and history.

```text Usage
keel
```

```bash Examples
keel
keel shell
```

### keel serve

Open the same terminal in your browser. On this machine only, unless you add --public-url (behind an HTTPS tunnel) or --host; both need a passkey login.

```text Usage
keel serve [--port 4242] [--public-url https://<name>] [--host <address> --cert <file> --key <file>]
```

```bash Examples
keel serve
keel serve --public-url https://keel.example.ts.net
```

### keel db

Show where your data lives, or sync it across devices.

```text Usage
keel db | keel db connect <address> | keel db disconnect
```

```bash Examples
keel db
keel db connect libsql://keel-<you>.turso.io
keel db disconnect
```

### keel auth

Pair your phone with a passkey for keel serve --public-url, and see or end its sessions.

```text Usage
keel auth | keel auth passkey add|list|remove | keel auth sessions [revoke <id>|--all]
```

```bash Examples
keel auth
keel auth passkey add --name "My iPhone"
keel auth passkey remove "My iPhone"
keel auth sessions revoke --all
```

### keel completion

Print the shell completion script.

```text Usage
keel completion zsh|bash
```

```bash Examples
echo 'eval "$(keel completion zsh)"' >> ~/.zshrc
```

### keel --version

Print the installed version.

```text Usage
keel --version
```

```bash Examples
keel --version
```
